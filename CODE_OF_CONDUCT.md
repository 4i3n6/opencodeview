# Code of Conduct

## Standard

OpencodeView is a small open-source project for developers. Participation in issues, pull requests, discussions, and other project spaces must stay respectful and professional.

Expected:

- Clear, technical discussion focused on the problem
- Respect for differing experience levels and viewpoints
- Constructive review feedback, given and received
- Credit where prior art or other reporters already advanced the thread

Unacceptable:

- Harassment, insults, or derogatory comments (public or private)
- Personal or political attacks
- Publishing others' private information without explicit permission
- Conduct that would be out of place in a professional engineering setting

## Scope

This Code applies in all project spaces (issues, PRs, discussions, code review) and when someone is representing the project publicly.

## Enforcement

Report unacceptable behavior via GitHub's tools or by contacting the maintainer through private channels appropriate to the severity. Security-sensitive reports belong in [SECURITY.md](SECURITY.md), not public issues.

Maintainers may remove or reject comments, commits, code, issues, and other contributions that violate this Code. Maintainers who do not enforce it in good faith may be removed from the project team.
